# Compliance: fair play, licenses, models

## Overview
Two rules can disqualify the team regardless of score: **(1) only the provided data — no external database, API, service, geocoder or internet data to look up businesses or resolve entities**, and **(2) the final model must be MIT or Apache-2.0 and ≤ 8B parameters**. The code is audited from the zip. Default answer to "can we use this external thing?" is **no** unless it is a local, permissively licensed library/model that uses only the provided data.

## When to use
- Before adding any dependency or model, before every upload, before zipping, when a teammate proposes an API.

## Quick reference
| Question | Answer |
|---|---|
| Groq API (any model, incl. "8B") | **No.** Sending records to a hosted LLM to decide matches = external service resolving entities → disqualification. Also no Groq model is both ≤ 8B and MIT/Apache (Llama 3.1 8B = Llama Community License, 8.03B; `llama-3.1-8b-instant` left free/dev tiers 2026-08-16; gpt-oss-20b is 20.9B), and a key-dependent call is not reproducible from the zip. |
| OpenAI / Anthropic / Bedrock / Gemini / any hosted model with data | **No** (same rule). Never paste competition data into a console playground either. |
| Geocoding, libpostal/usaddress-style parsers trained on external data, downloaded city/ZIP/PIN lists, web scraping | **No** (external data). |
| Hand-written abbreviation, legal-form and state maps in code | **Yes** — general domain knowledge, documented as such. |
| Artifacts learned from the provided train data (native-token dictionary, models) | **Yes** — must be regenerated by the submitted code. |
| Final model | LightGBM booster (MIT library, trained by us). |
| Local open-weights MIT/Apache ≤ 8B models (encoders, cross-encoders, small LLMs) | Allowed, run on the laptop or the team's own EC2. List them in `models_manifest.json` with exact params. |
| Your own AWS EC2/S3 compute | Allowed (compute you control, not a lookup service). |
| API keys in code, notebooks, skills or chat | **Never.** A Groq key was pasted in chat on 2026-09-25 — it must be revoked, never reused, never written anywhere. |

## Audit before upload and before zipping
```bash
.venv/Scripts/python .claude/skills/er-compliance-licensing/audit_compliance.py code/business_entity_resolution --report work/compliance_report.md
.venv/Scripts/python .claude/skills/er-compliance-licensing/audit_compliance.py --count-params work/models/final/*.txt
```
Stdlib only, no network, secrets redacted. FAIL on: API clients / HTTP calls / hosted-model SDKs, forbidden packages, key-like strings or key env vars, unpinned or GPL/AGPL requirements, models missing from the manifest, license ∉ {MIT, Apache-2.0}, params > 8,000,000,000 (exact integer; re-counted from files when present). Exit 0 = PASS. Self-test: `--self-test` (22 FAIL + 10 WARN planted violations caught). Put the Markdown report into Documentation Appendix B.

Manifest: copy `models_manifest_template.json` to `code/business_entity_resolution/models_manifest.json`, fill ids, licenses, evidence, exact params; ship it with `package_submission.py --extra code/business_entity_resolution/models_manifest.json` (name it in README.md).

## Common mistakes
| Mistake | Fix |
|---|---|
| "The Groq model is small/free, so it is fine" | rule is about the external service, not size — forbidden |
| Qwen2.5-**3B** assumed Apache (it is `qwen-research`) | check the HF license tag per exact repo |
| Qwen3-8B / Llama-3.1-8B assumed ≤ 8B (8.19B / 8.03B) | exact `safetensors.total` ≤ 8,000,000,000 |
| `trust_remote_code=True` models (gte-multilingual, arctic-embed-m-v2) | avoid or pin `revision`; document |
| `pip freeze` shipping GPL/AGPL/API clients | hand-written requirements (er-submission-packaging) |
| Using the console Bedrock playground with competition data for the $20 credit activity | only a generic prompt like "hello" |
| Downloading "just a list of Indian states/US cities" | write the small maps by hand in code; no downloaded gazetteers |
